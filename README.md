# Unlimited Game Maker

世界最大級・世界最高峰のハイクオリティを誇る、1,000,000,000種類の完全に異なる3Dアドベンチャー自動生成ブラウザゲームプラットフォーム。

## Cloudflare Pages へのデプロイ手順

1. このフォルダ内のファイルを準備します。
2. Cloudflare ダッシュボードにログインし、「Workers & Pages」 > 「Pages」 > 「Create application」を選択します。
3. 「Direct Upload」を選択し、本フォルダをアップロードします。
4. ビルド設定：
   - **Build command:** (空欄でOK)
   - **Build output directory:** `.` (ルートディレクトリを指定)
5. デプロイ完了後、世界最高峰の3Dエンジンとマルチ言語（JP/EN/KO）対応の『Unlimited Game Maker』が即座に公開されます。
